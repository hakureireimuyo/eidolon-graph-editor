# 节点视觉渲染方案 v3 —— 三色圆点端口 + 域分类 + 四层渲染架构

> 替代 v2(方法带方案)。核心立场延续 v2:**节点长什么样,由内核声明推导,编辑器零硬编码**;
> v3 在此基础上做三件事:(1) 内核新增 `category` 域分类(七值严格枚举),分类信息不再靠
> 声明形态猜测;(2) 端口语言极简化为**三色圆点**(废除形状符号与徽标,符号仅保留异常标记);
> (3) 渲染代码重构为 **L0 派生 / L1 结构 / L2 元素 / L3 状态** 四层。
> 相关:内核 `model/node.py`(category,1.3)、`model/types.py`(七值枚举)、
> `engine/snapshot.py`(运行快照)。

---

## 0. 为什么废弃 v2(方法带方案)

v2 的四带结构(方法带/信号栏/源产出带/状态带)方向正确,已落地;v3 不推翻带结构,推翻三件事:

| v2 问题 | v3 修正 |
|---|---|
| **形状符号过载**:●实心/◯空心/▢方块/⚡闪电四种形状 + 六种徽标(▶⊞⌘⌨⏳⚠),视觉噪音大、字体渲染不一致 | 端口 = **圆点一种形状,仅三色区分**(数据蓝/信号绿红/触发橙);徽标全部废除,分类由**域色**承担;符号仅保留熔断异常一个 |
| **分类靠形态猜测**:调色板"信号运算 vs 基础"两档派生自 control_out,把 LlmCall(有 failed 控制输出)错分进信号运算 | 内核 `category` 七值严格枚举(signal/data/source/encapsulation/host/custom/test),声明必填、构造点校验;调色板按枚举分组 |
| **渲染逻辑单文件**:GraphNode.jsx 313 行,派生/结构/原子/运行时态混杂,调色板无法共用视觉语言 | L0-L3 四层拆分;派生层为纯函数(零 JSX),画布与调色板同源 |
| **句柄内缩**:数据点距边界 9px,信号/数据两根线的接入点在水平方向错开——线到点处交叉 | 信号点+数据点**竖直堆叠**且**都贴节点边界**——每条对外连线到达独一无二的高度,不交叉 |
| **Input/Output 名字硬编码** | `category='host'` 派生宿主交互;交互挂载点由编辑器侧 HOST_INTERACT 表约定(两行,见 §9) |

## 1. 内核侧:category 七值严格枚举(1.3)

```python
Category = Literal["signal", "data", "source", "encapsulation", "host", "custom", "test"]
```

| 值 | 含义 | 内置节点 |
|---|---|---|
| `signal` | 纯信号运算元件 | AND / OR / NOT / Latch |
| `data` | 数据节点 | Join / Buffer / Switch / Threshold / Comparator / Counter / Random |
| `source` | 自走源节点 | Clock / Timer |
| `encapsulation` | 封装节点(LLM 调度) | LlmCall / ContextStore / ContextCompile |
| `host` | 宿主交互节点 | Input / Output |
| `custom` | 自定义节点 | 子图 / 脚本(编译产物自动 custom) |
| `test` | 测试节点(验证系统运行/渲染效果,非基础) | MultiGate / Simulate |

- **域与形态正交**:信号节点/自走/子图仍由声明派生(徽标已废,形态由带结构表达:自走→自产带);
  category 只回答"哪个域"。
- **严格枚举**:声明必填(`NodeType.__post_init__` 构造点校验);旧资产反序列化缺字段兜底 custom;
  显式非法值拒绝。序列化带出,编辑器零后端改动收到。

## 2. 端口视觉语言:三色圆点

| 端口 | 视觉 | 规则 |
|---|---|---|
| 数据端口 | **蓝色圆点**(恒定) | 值载体;不随状态变 |
| 信号端口 | **圆点,按电平填色** | 激活=绿 / 失效=红 / 未运行=灰。数据端口的绑定信号点、节点级控制端口(enable/level/控制输出)统一都是信号点;enable 的"闸门"语义只进 tooltip |
| 触发端口 | **橙色圆点**(恒定) | 调用级激活入口;位于组头 |

- 形状全同(9px 圆点),仅颜色区分——色弱友好性靠 tooltip 与标签兜底;
- **每个数据端口恒有一对竖直堆叠的点**(信号上、数据下,间距 4px);
- **句柄原点都在节点边界**(左/右 0,不内缩):端口是暴露在外的接线端子,不是节点内部元素;
  对外连线按竖直偏移自然分流,不交叉;
- 废除:▢ 门控方块、⚡ 闪电、空心环、全部徽标符号;节点上**唯一符号 = 熔断红三角**(SVG,仅异常时出现)。

## 3. 节点解剖学:头部 + 组单元 + 带

```
┌──────────────────────────────────────┐
│║ Clock                       n3ab    │ ← 头部:域色条(左缘 3px)+ 类型名
│  set_rate                            │    + 熔断红三角(异常时)+ id(选中时)
│    ◉ rate=1                ◉         │ ← 组单元:组头(函数名)+ 组身
│    ●                        ●        │    参数列/输出列(每端口一行,
│║ ·自产                 ◉ count        │    一对点竖直堆叠贴边界)
│║                    ◉                │ ← 源产出带(auto 节点未入组输出)
│║ ● enable                           │ ← 信号栏(节点级控制端口)
│  count=12 · rate=1                   │ ← 运行读值带(快照驱动)
│  duration=5                           │ ← 配置带(选中/hover;暗=默认,亮=覆盖)
└──────────────────────────────────────┘
```

带决策表(由声明派生,零硬编码):

| 带 | 出现条件 |
|---|---|
| 头部 | 总是 |
| 构造带(init) | `init_in` 非空(预埋,当前无节点使用) |
| 组单元 | 每个 `groups` 条目各一个 |
| 信号栏 | `control_in` 或 `control_out` 非空 |
| 源产出带 | 存在未入组 `data_out`(≈ auto 节点) |
| 运行读值带 | 运行时(state 非空) |
| 配置带 | config 声明非空(选中/hover 显示) |

### 组单元:组头(函数)+ 组身(参数列表)

```
│ ●trigger arm                 │ ← 组头:触发点(橙,贴边界)+ 函数名
│   ◉ delay?        ⇒  ◉       │ ← 组身:参数列(标签缩进 34px)/ 输出列
│   ●                   ●      │    连词符垂直居中;空方法不画连词符
│                     ◉ out    │
│                     ●        │
```

- **触发是激活函数语义 → 触发点位于组头**(函数名旁),不在组身;
- 组身两列独立堆叠(参数列 / 输出列),**互不对齐**(组 = 函数,输入→输出经由方法,不经由行号);
- 触发端口名显示规则:下划线开头(`_result`)= 实现细节 → 隐藏名字,只留橙点;
- **连词符 = 触发策略**(纯箭头,⚡ 被禁):
  `on_all_data_ready` → `→` / `on_any_data` → `↝` /
  `on_trigger` 与 `on_data_and_trigger` → `⇒`(完整策略名进 tooltip);
- 组刚触发(fresh / trigger_fresh)→ 组单元脉冲高亮 ~500ms。

## 4. 头部与域色

- **域色条**:节点左缘 3px,域分类的唯一颜色载体;映射表在 L2 元素层(编辑端展示关切):

| category | 域色 | 调色板组名 |
|---|---|---|
| signal | 橙 `#f59e0b` | 信号运算 |
| data | 蓝 `#3b82f6` | 数据节点 |
| source | 绿 `#22c55e` | 源节点 |
| encapsulation | 紫 `#a78bfa` | 封装节点 |
| host | 青 `#22d3ee` | 宿主交互 |
| custom | 灰 `#94a3b8` | 自定义 |
| test | 深灰 `#6b7280` | 测试节点 |

- hover 节点 → doc summary tooltip(内核 `impl.doc()`);
- 节点 id 仅选中时显示;无任何徽标。

## 5. 端口细节

- **类型注解**:hover 端口 tooltip 显示(`rate:int · 默认=1(不参与触发) · 信号点:该端口是否启用`);节点面不加小字(保持简洁);
- **绑定端口**(const/全局读取)标签带后缀(`=1` / `@g`)且暗色,提示"不参与触发";
- **optional 参数**标签后加 `?`;
- 控制端口语义(enable 门控 vs level 电平)只进 tooltip,不靠形状。

---

## 6. 运行时态(WS 快照驱动,L3)

| 状态 | 视觉 |
|---|---|
| 信号电平 高/低 | 信号点绿/红(含组身对点、信号栏、边);未运行灰 |
| 组刚触发 | 组单元脉冲 |
| 状态字段 | 读值带:`count=12 · rate=1`;**标量原样上脸,对象/数组显示占位**(`{…}` / `[n 项]`),不截断长文本撑宽节点 |
| 熔断(circuit_open) | 红边框 + 头部红三角(SVG,唯一符号),fault_count 进 tooltip |
| 异步等待(pending) | 无符号——`pending` 状态字段已在读值带自然显示 |

---

## 7. 边与连接(沿用 v2 已验证系统)

- 数据边蓝;信号边按电平绿/红;**触发边:数据线 → 蓝→橙渐变,信号线 → 纯橙**(触发端口色从黄 `#eab308` 改为橙 `#f97316`);
- 句柄 id 约定不变:`{in|out}:{slot}:{端口名}`,GraphCanvas 边映射/onConnect/校验逻辑零改动;
- **性能**:连线索引 `Map(dst_node|dst_port|slot → wire)`,signalLevels 由 O(端口×连线) 降为 O(端口)——快照高频刷新热路径。

## 8. 四层渲染架构

| 层 | 文件 | 职责 |
|---|---|---|
| L0 派生 | `src/nodeModel.js` | spec+快照 → 纯数据渲染模型(形态/域色/组单元/带决策);零 JSX 可单测;GraphNode 与 NodePalette 共用 |
| L1 结构 | `components/GraphNode.jsx` | 消费模型 → 头部+带骨架;无派生逻辑 |
| L2 元素 | `components/NodeAtoms.jsx` | 原子词汇:三色圆点端口行、域色条、熔断红三角、chip |
| L3 状态 | `components/GraphCanvas.jsx` | 快照→电平/脉冲(连线索引);边渲染 |

视觉语言改版只动 L1/L2(纯 JSX/CSS);语义接线不动 L0。新节点类型(含子图/脚本)套用同一决策表自动获得正确形态。

## 9. 宿主交互(编辑器侧契约)

- Input/Output 由 `category='host'` 识别,删除 `spec.name` 特判;
- 交互挂载点由两行表约定(`nodeModel.js` HOST_INTERACT):Input → 节点面注入栏(选中浮现);
  Output → 控制台「节点」tab 日志视图(NodeDetails 注册视图,既有机制);
- 注入栏、日志对接与后端 service 的 Output/Input 特殊处理一一对应——交互契约在编辑器,
  不在节点面上做视觉特判。

---

## 10. 调色板

- 分组 = 内核七值枚举声明序(signal → data → source → encapsulation → host → custom → test,
  测试节点垫底,不占常规视线),未知分类兜底「其他」;
- 组标题与条目带**域色点**(与节点面域色条同源);条目显示端口概要(in/out/trig/c-in/c-out/组数);
- 点击弹说明书悬浮窗、拖入画布添加节点(既有交互不变)。

**风险点**:

- 端口行 = 每端口一行 → 多端口节点(Comparator 2 参数 2 输出)节点面变高;行高 26px,可接受;画布密集时按需 zoom。
- 多触发端口同组(内核暂无)会叠在组头同一点——罕见,出现时再处理。
- 竖直堆叠对点间距 4px,误点风险低(句柄 9px);若实机观感需调整,纯 CSS 参数。
